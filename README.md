# Bugzilla

## Firefox project-history QA course study

This repository hosts **Memorize, Retrieve, or Query? LLMs Answering Questions about a Software Project's History**. The authoritative plan is [`docs/reference/research_roadmap.tex`](docs/reference/research_roadmap.tex).

The required comparison is M0 closed-book, M1 BM25 RAG, M2 hybrid retrieval, and M3 parameterized SQL. M4 small-graph retrieval is optional. The benchmark target is 180 generated candidate questions across F1–F6; temporal evaluation compares v0/v1 snapshots. These are study targets, not completed systems or results.

The downloaded files remain under the root-level `Dataset/` and are Git-ignored. Do not modify or copy the source datasets or the upstream `Dataset/EASE_2025_Data_paper/` clone. This existing repository's `origin` is `https://github.com/ahmadfaisal9900/Bugzilla.git`; do not change it.
